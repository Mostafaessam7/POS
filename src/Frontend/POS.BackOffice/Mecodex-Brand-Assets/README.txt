Mecodex — Brand Assets (Tech / Network Direction)
====================================================

مجلد SVG (فيكتور، يكبر لأي حجم من غير ما يخس):
- mecodex-logo-for-dark-bg.svg   -> اللوجو كامل لخلفية غامقة (نص فاتح)
- mecodex-logo-for-light-bg.svg  -> اللوجو كامل لخلفية فاتحة (نص غامق)
- mecodex-icon.svg               -> الأيقونة لوحدها، خلفية شفافة
- mecodex-favicon.svg            -> الأيقونة بخلفية مربعة غامقة جاهزة

مجلد PNG:
- Icon/            -> الأيقونة لوحدها: 64, 128, 256, 512, 1024px (خلفية شفافة)
- Favicon/         -> فافيكون: 16, 32, 192, 512px
- Logo-Lockup/     -> اللوجو كامل بدقة عالية (خلفية شفافة)
- Social-Profile/  -> صورة بروفايل دائرية (400 و800px) + غلاف لينكدإن/فيسبوك (1584×396)

Favicon-ICO/
- favicon.ico -> جاهز يترفع على جذر الموقع مباشرة

الألوان الرسمية:
- Teal:  #33E0C7
- Blue:  #3D6CF2
- Ink Dark (خلفيات):  #0A0F1C
- Ink Light (نص فوق الغامق): #EAF6FF

الخط: IBM Plex Mono SemiBold — النص محول لمسارات Vector فمش محتاج الخط يكون متثبت على أي جهاز هيفتح بيه الملف.
